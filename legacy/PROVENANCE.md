# Legacy benchmark scripts: provenance and mining plan

Collected 2026-09-18. Nothing here is maintained; each file is a frozen copy kept so the knowledge it encodes can be reproduced as a case in the new harness (`benchmarks/abtem_bench` in the abTEM repository, see `../design/DESIGN.md`). Per Toma Susi's request in abTEM discussion #380, a script is deleted from the abTEM repository only after the "reproduced by" column below points at a merged case; the copy here stays forever.

Columns: file, source (repo @ commit, date of last change), lines, what it measures, knowledge worth mining, which harness component or case reproduces it.
